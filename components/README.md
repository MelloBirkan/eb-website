# Components

Component folders are grouped by how they are used:

- `ui/` contains reusable application primitives such as buttons, inputs, dialogs, navigation shells, and form controls.
- `elements/` contains small marketing/site building blocks used by page sections.
- `sections/` contains full-width page sections assembled by the routes in `pages/`.
- `icons/` contains shared icon components, with social icons under `icons/social/`.
